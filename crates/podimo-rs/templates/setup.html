How to change LIBRARY_DIR

The path itself is configured via the LIBRARY_DIR environment variable (read once at startup). To switch:

  1. Edit .env (or your compose file's env block) to point at the new path.
  2. Make sure the same path is volume-mounted into the container.
  3. Probe the candidate path above to confirm.
  4. Restart the container.

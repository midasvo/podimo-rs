Add an audiobook by URL or UUID. The server fetches the metadata, then downloads the audio + cover to disk in the background. Files stay yours, even if you cancel your Podimo subscription.

+ Sharing this directory with an existing Audiobookshelf library?

podimo-rs is conservative about the files it touches:

  • It refuses to add a book if the target Author/Title/ directory already exists. You'll see a clear error pointing at the path — move or rename your existing book first if you want podimo-rs to manage it.
  • The Forget button below only removes podimo-rs's own state marker (podimo-state.json). Audio file, cover, and Audiobookshelf metadata stay on disk; the book stays visible to ABS.
  • podimo-rs never deletes books it didn't add. To wipe an audio file, do it from the filesystem yourself.
